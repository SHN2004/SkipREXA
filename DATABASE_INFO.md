# Database Information

This repository comes pre-configured to connect to a **public, read-only** Supabase instance. You **do not** need to set up your own database to run this extension; it will work out-of-the-box using the provided credentials.

## Access Level

*   **Read Access:** The included API keys allow you to query (SELECT) data from the `question_papers` table.
*   **Write Access:** Disabled. Row Level Security (RLS) is enforced to prevent unauthorized `INSERT`, `UPDATE`, or `DELETE` operations.

## Table Schema: `public.question_papers`

If you are exploring the code or want to understand the data structure being fetched, here is the schema for the main table:

```sql
create table public.question_papers (
  id bigint generated by default as identity not null,
  sl_no text null,                      -- Serial number
  question_paper_code text null,        -- Unique code on the physical paper
  course_name text null,                -- Name of the course (e.g., "Mathematics I")
  course_code text null,                -- University course code
  actual_subject_code text null,        -- Specific subject code
  semester text null,                   -- e.g., "First Semester", "Second Semester"
  exam_type text null,                  -- e.g., "Regular", "Supplementary"
  admission_year integer null,          -- Year of admission
  exam_month text null,                 -- Month the exam was held
  exam_year integer null,               -- Year the exam was held
  download_url text not null,           -- Public URL to the PDF file
  raw_exam_details text null,           -- Raw metadata string
  created_at timestamp with time zone null default now(),
  
  constraint question_papers_pkey primary key (id),
  constraint question_papers_download_url_key unique (download_url)
) TABLESPACE pg_default;
```

## Data Privacy & Security

*   The credentials in `supabase-client.js` are `anon` (public) keys.
*   The database is protected by RLS policies that only allow public access to fetch data.
*   Attempting to modify the database with these credentials will result in a 401/403 error.
